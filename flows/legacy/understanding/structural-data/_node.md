# Понимание: Структурные данные (structural-data)

## Гипотеза
Этот узел объединяет модели данных и вспомогательные функции, которые обеспечивают логику работы со стихами и их диапазонами.

## Источники
- `lib/src/models/verse_range.dart`
- `lib/src/utils/group_consecutive.dart`
- `test/group_consecutive_test.dart`

## Валидированное понимание
Узел содержит фундаментальные структуры данных и алгоритмы для группировки стихов:
1. **Модель `VerseRange<T>`**:
   - Обобщенный класс для хранения группы элементов (`items`) и их текстовой метки (`label`).
   - Поддерживает `semanticsLabel` для доступности (Accessibility).
   - Предоставляет удобный доступ к первому элементу (`representative`) и проверку наличия элемента по предикату.
2. **Алгоритмы группировки (`utils/`)**:
   - `group_consecutive_runs`: Универсальная функция группировки отсортированных элементов на основе кастомного предиката смежности.
   - `group_consecutive_by_position`: Специализированная версия для группировки по целочисленной позиции (например, порядковые номера стихов).
   - Логика полностью покрыта юнит-тестами.
