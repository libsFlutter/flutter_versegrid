# Requirements: verse-widgets

> Version: 1.0  
> Status: DRAFT (Legacy)  
> Last Updated: 2026-05-05

## Goals
Предоставить основные UI-компоненты для отображения священных текстов (стихов) и навигации по ним.

## User Stories
- Как читатель, я хочу видеть текст стиха с переводом в удобном формате.
- Как читатель, я хочу иметь возможность переключаться между различными режимами отображения (строчный, колоночный) в зависимости от устройства.
- Как пользователь, я хочу видеть компактную сетку номеров стихов для быстрой навигации.

## Key Features
- Виджет `VersePassage` для отображения строк текста с поддержкой различных макетов.
- Виджет `VerseRangeChipStrip` для отображения чипов навигации.
- Интеграция с `VerseGridTheme` для управления отступами и размерами шрифтов.
