# Понимание: Система дизайна (design-system)

## Фаза: EXPLORING

## Гипотеза
Этот узел отвечает за визуальный стиль пакета, включая цветовые палитры и темы оформления виджетов. Он обеспечивает консистентность отображения стихов в различных режимах (светлый/темный) и состояниях.

## Источники
- `lib/src/theme/verse_grid_color_palette.dart`
- `lib/src/theme/verse_grid_theme.dart`
- `flows/sdd-color-palette/`

## Валидированное понимание
Система дизайна пакета состоит из двух основных частей:
1. **Цветовая палитра (`VerseGridColorPalette`)**:
   - Основана на дизайне "HRISHIKESH SWAMI".
   - Определяет семантические цвета: `forest` (зеленый), `gold` (золотой), `paper` (белый/фон), `ink` (черный/текст).
   - Предоставляет готовую `lightColorScheme` и метод `lightTheme()` для быстрой настройки темы приложения.
2. **Тематизация виджетов (`VerseGridTheme`)**:
   - Реализована как `ThemeExtension`.
   - Содержит специфичные для пакета параметры: отступы (`rowVerticalPadding`), ширину колонок для номеров стихов (`verseNumberColumnWidth`), размеры шрифтов и промежутки между оригиналом и переводом.
   - Поддерживает интерполяцию (`lerp`) для плавной смены тем.
